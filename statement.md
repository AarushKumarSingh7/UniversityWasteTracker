# Project Statement

## Project Title
University Waste Tracker

## Problem Statement
A university produces waste from several locations such as academic blocks, hostels, canteens, libraries and sports areas. The waste may belong to different categories such as food, paper and plastic. A simple computational method is required to record the quantity of waste and calculate useful summaries.

## Scope
The project records waste during a program session and provides basic calculations and reports. It does not use a database, web application, graphical interface, machine learning or external Python libraries.

## Target Users
- University students
- University staff
- Waste-management volunteers

## High-Level Features
1. Add waste records.
2. Display all waste records.
3. Calculate total waste.
4. Analyse waste by category.
5. Analyse waste by university location.
6. Analyse waste by date.
