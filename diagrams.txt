4. SEQUENCE DIAGRAM

User -> main.py: Select option
main.py -> tracker.py: Add/display record
tracker.py -> data.py: Read categories/locations
tracker.py -> main.py: Return result
main.py -> reports.py: Request report
reports.py -> algorithms.py: Calculate result
algorithms.py -> reports.py: Return result
reports.py -> main.py: Return report
main.py -> User: Display result
