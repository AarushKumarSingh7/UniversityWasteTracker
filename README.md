# University Waste Tracker

## 1. Project Overview

University Waste Tracker is a simple Python console application for recording and analysing waste generated at different locations of a university.


## 2. Problem

A university generates different types of waste in places such as the canteen, hostel, academic block 1,2 and architecture , library and sports area. Without a simple record and calculation system, it is difficult to know the amount and type of waste generated.

## 3. Solution

The program allows a user to:
- Add a waste record.
- View all records.
- Calculate total waste.
- Calculate category-wise waste.
- Calculate location-wise waste.
- Calculate date-wise waste.
